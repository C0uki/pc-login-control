# ③ 導入チェックリスト（1枚）

上から順にチェックしていけば導入完了です。詳細は各手順書へリンクしています。

---

## A. オーナー：初回セットアップ（一度だけ）
→ 詳細: [① バックエンド接続手順](01-backend-setup.md)

- [ ] Supabase でプロジェクト作成
- [ ] **Project URL** と **service_role キー** を控えた（Settings → API）
- [ ] Vercel に `SUPABASE_URL` を追加
- [ ] Vercel に `SUPABASE_SERVICE_ROLE_KEY` を追加
- [ ] （任意）`SIGNUP_CODE` を追加して組織作成を制限
- [ ] Vercel を **Redeploy** した
- [ ] コンソール `/` を開き、スキーマSQLを Supabase で実行
- [ ] 「再確認」で **導入状態がすべて 🟢**
- [ ] 導入者に **コンソールURL** を共有した（`SIGNUP_CODE` を使うなら合言葉も）

## B. 導入者：組織のセットアップ（組織ごと）
→ クラウド操作は不要。ブラウザだけ

- [ ] コンソールURL を開いた
- [ ] 「組織を作成」→ 組織名＋管理者パスワードを入力
- [ ] 表示された **組織ID を保存**した（アプリ設定で使う）
- [ ] 「組織にログイン」で管理画面に入れた
- [ ] 「ユーザー」タブで利用者を登録した（ID・名前・初期パスワード）

## C. クライアントアプリ（PC / スマホ）
→ 詳細: [② ビルド手順](02-build-clients.md)

- [ ] `react-native/packages/core/src/config.ts` に `API_URL`（Vercelの `…/api`）を設定
- [ ] 同ファイルに自組織の `ORG_ID` を設定
- [ ] `cd react-native && npm install`
- [ ] PC: `react-native-windows-init` → `KioskModule.cs` 組み込み → `npm run windows:release`
- [ ] PC: 管理者として実行し、キオスク動作を確認
- [ ] スマホ: `npm run android`（または iOS）でビルド
- [ ] 対象PC・対象スマホにアプリを配布した

## D. 動作確認（受け入れテスト）

- [ ] PC で **ID＋パスワードの直接ログイン**が成功する
- [ ] PC で「スマホで承認」→ スマホアプリの「承認」タブに表示される
- [ ] スマホで承認 → PC がログインしてバックグラウンドに入る
- [ ] コンソールの「利用ログ」に login / logout が記録される
- [ ] 未登録ID・誤パスワードでログインが拒否される

## E. 運用（日常）

- [ ] ユーザーの追加 / 削除 → コンソール「ユーザー」タブ
- [ ] 利用状況の確認 → 「利用ログ」タブ
- [ ] スマホ承認の対応 → 「承認」タブ

---

### 覚えておくこと
- **Ctrl+Alt+Del は塞げない**（OS 仕様）
- `service_role` キーは Vercel の環境変数だけに置く（公開しない）
- 自分のPCだけの管理なら、組織は1つ作れば十分（マルチテナントは他組織に配る時に効いてくる）
