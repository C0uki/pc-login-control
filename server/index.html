🔐 PC Login Control 管理コンソール

通常は空欄でOK（このページと同一オリジンの /api を使用）。 別の場所から開く場合のみ、API の URL を入力してください。

Supabase や Vercel の操作は不要です。組織を作成して、あなたの組織の ユーザー・ログ・承認をこの画面から管理できます。

組織を作成（はじめての方）

組織名と管理者（マスター）パスワードを決めるだけ。作成後に表示される 組織ID を、PC・モバイルアプリに設定します。

✅ 組織を作成しました。次のIDをアプリに設定してください。

この組織IDと管理者パスワードで、下の「組織にログイン」から管理できます。
