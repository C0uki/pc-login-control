🔐 PC Login Control 管理コンソール

このコンソールを Vercel から開いた場合は空欄（同一オリジンの /api）でOK。 ローカルで開いた場合はデプロイ後の …/api を入力してください。

① 導入状態

API 接続
環境変数(Supabase)
マスターPW
DBテーブル

② マスターパスワードのハッシュ生成

生成した値を Vercel の環境変数 MASTER_PASS_HASH に設定してください（デプロイ時に入力）。

③ データベース初期化

Supabase の「SQL Editor」に貼り付けて実行してください（初回のみ）。実行後「①再確認」で DBテーブル が緑になれば完了です。
